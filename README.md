# AI-Assisted Real-Time Emotion Recognition for Therapy Sessions

## Objective
Develop a real-time emotion recognition system using MobileNetV2,
optimized for accuracy and latency.

## Models
- MobileNetV2 (baseline)
- Whisper (ASR support)

## Focus
- Emotion recognition accuracy
- Real-time performance (FPS & latency)
- Model fine-tuning and improvement
